# Deploy ParkLane on Render

Render hosts the **API + Admin UI** and the **ALPR** scanner.  
MySQL is **not** provided by Render — use a free external MySQL, then point env vars at it.

## Architecture

```
Browser  →  parkingsystem-api  (Node + React build)
                ├─ /api/*  MySQL (external)
                └─ ALPR → parkingsystem-alpr (Docker / Tesseract)
```

## 1) Create a MySQL database (required)

Pick one free/cheap host and create a database named `parking`:

| Provider | Notes |
|---|---|
| [Aiven](https://aiven.io) | Free trial MySQL, gives host/user/password/SSL |
| [Railway](https://railway.app) | MySQL plugin, copy connection vars |
| [FreeSQLDatabase](https://www.freesqldatabase.com/) | Free MySQL (limits apply) |
| [db4free.net](https://www.db4free.net/) | Free MySQL for testing |

Save:

- `DB_HOST`
- `DB_PORT` (usually `3306`)
- `DB_USER`
- `DB_PASSWORD`
- `DB_NAME` → `parking`

## 2) Push this repo to GitHub

`main` (or this branch) must be on GitHub so Render can pull it.

## 3) Deploy with Render Blueprint

1. Open [https://dashboard.render.com](https://dashboard.render.com)
2. **New → Blueprint**
3. Connect `Aagam1754/ParkingSystem` (or your fork)
4. Render reads `render.yaml` and creates:
   - `parkingsystem-api` (web)
   - `parkingsystem-alpr` (Docker web)
5. When prompted, paste your MySQL env values (`DB_HOST`, `DB_USER`, `DB_PASSWORD`, …)
6. Click **Apply**

## 4) Initialize schema + seed (one time)

After the API service is live, open its **Shell** (or use any MySQL client) and run locally against the remote DB:

```bash
# From your laptop, with backend/.env pointing at the Render MySQL:
cp backend/.env.example backend/.env
# edit DB_* to the remote MySQL values, set DB_SSL=true

npm install --prefix backend
npm run db:init --prefix backend
npm run db:seed --prefix backend
```

Login after seed:

- Email: `admin@parking.local`
- Password: `Admin@123`

## 5) Open the live site

Render gives a URL like:

`https://parkingsystem-api.onrender.com`

That single URL serves:

- Admin UI (`/`)
- API (`/api/...`)
- Socket.io (`/socket.io`)

### Free plan note

Free web services **sleep after ~15 min** idle. First request after sleep can take 30–60s. Upgrade to Starter if you need always-on.

## 6) Optional env vars

In `parkingsystem-api` → Environment:

| Key | Purpose |
|---|---|
| `JWT_SECRET` | Auto-generated by blueprint (keep it) |
| `OPENAI_API_KEY` | Smart Parking Assistant LLM |
| `ELEVENLABS_API_KEY` | Assistant voice TTS |
| `CLIENT_ORIGIN` | Leave `*` or set your exact site URL |
| `DB_SSL` | `true` for most cloud MySQL hosts |

## 7) Manual deploy (without Blueprint)

### A) ALPR service

- **New → Web Service → Docker**
- Root: `alpr-service`
- Dockerfile: `Dockerfile`
- Health: `/health`

### B) API + Admin

- **New → Web Service → Node**
- Build:
  ```bash
  npm install --prefix backend && npm install --prefix admin && npm run build --prefix admin
  ```
- Start:
  ```bash
  npm start --prefix backend
  ```
- Env:
  ```
  SERVE_ADMIN=true
  NODE_ENV=production
  CLIENT_ORIGIN=*
  DB_HOST=...
  DB_PORT=3306
  DB_USER=...
  DB_PASSWORD=...
  DB_NAME=parking
  DB_SSL=true
  PYTHON_ALPR_URL=https://<your-alpr-service>.onrender.com
  JWT_SECRET=<long-random>
  ```

## Troubleshooting

| Symptom | Fix |
|---|---|
| `/api/health` fails / DB error | Check `DB_*` + `DB_SSL=true`; whitelist Render IPs if your MySQL requires it |
| Login fails | Run `db:init` + `db:seed` against the remote DB |
| Plate scan fails | Confirm `PYTHON_ALPR_URL` points at the ALPR service URL (https, no trailing slash) |
| Site blank | Confirm `SERVE_ADMIN=true` and admin `npm run build` succeeded in build logs |
| Cold start slow | Free tier sleep — wait once, or upgrade plan |
